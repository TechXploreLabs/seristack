Examples

Practical YAML examples for the CLI, HTTP endpoints, and MCP tools.

Practical Seristack YAML. Every stack sets count: 1, because a stack with count: 0 is skipped. For field details, see the Config Reference.

1. A simple CLI stack

stacks:
  - name: hello
    count: 1
    cmds:
      - echo "Hello from Seristack"

seristack trigger -c config.yaml -s hello

2. Serve a stack over HTTP

Set method, and optionally urlPath.

stacks:
  - name: greet-api
    method: GET
    urlPath: /greet
    count: 1
    vars:
      - name: name
        value: engineer
    cmds:
      - echo "Hello {{.Vars.name}}"

seristack run -c config.yaml --addr 127.0.0.1 --port 8080
curl 'http://127.0.0.1:8080/greet?name=alice'

3. Expose a stack as an MCP tool

Set description.

stacks:
  - name: system-info
    description: Returns basic system information
    count: 1
    cmds:
      - uname -a

seristack mcp -t streamableHTTP --addr 127.0.0.1 --port 8081

4. Validate input

stacks:
  - name: deploy
    method: POST
    urlPath: /deploy
    count: 1
    vars:
      - name: env
        allowed_value: [dev, stage, prod]
      - name: service
        allowed_regex: regex("^[a-zA-Z0-9_-]+$")
    cmds:
      - echo "Deploying {{.Vars.service}} to {{.Vars.env}}"

Prefer allow-lists. A caller can only override variables declared here.

5. Dependencies

stacks:
  - name: build
    count: 1
    cmds:
      - echo "building"

  - name: test
    dependsOn: [build]
    count: 1
    cmds:
      - echo "testing"

6. Aggregate output

stacks:
  - name: collect
    count: 2
    executionMode: SEQUENTIAL
    cmds:
      - echo "{\"index\": {{.Count.index}}, \"status\": \"ok\"}"
    output: |
      echo '{{.Self.result}}' | grep "^{" | jq -s '{records: ., total: length}'

This needs jq installed. The single quotes around {{.Self.result}} break if the output contains a single quote.

7. Use another stack's output

stacks:
  - name: get_version
    count: 1
    cmds:
      - echo "v1.4.2"

  - name: announce
    dependsOn: [get_version]
    count: 1
    cmds:
      - echo "Releasing {{.Result.get_version}}"

Use underscores in stack names that other stacks read with .Result. Go templates reject -.

8. Use another shell or runtime

stacks:
  - name: with-bash
    count: 1
    executor: ["bash", "-c"]
    cmds:
      - echo "runs in bash"

  - name: with-python
    count: 1
    executor: ["python3", "-c"]
    cmds:
      - print("runs in python")

9. Command timeouts

stacks:
  - name: quick-check
    count: 1
    timeouts: 30s
    cmds:
      - curl -f http://localhost:8080/health

The timeout applies to each command. When it expires, the command and everything it started are killed immediately. Examples: 500ms, 30s, 5m, 1h, 1h30m.

10. Production-friendly binding

Bind to localhost and put nginx or Caddy in front for TLS, authentication, and rate limits.

seristack run -c config.yaml --addr 127.0.0.1 --port 8080
seristack mcp -t streamableHTTP --addr 127.0.0.1 --port 8081

See the Guide for the proxy setup.
